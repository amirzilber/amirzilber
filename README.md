# בורד מגמות לבורסה האמריקאית

דשבורד קליל ב-HTML/CSS/JS שמציג:

- תקציר מצב שוק (כמות סימבולים בעלייה/ירידה, שינוי ממוצע ומובילה יומית)
- טבלת מעקב לפי רשימת סימבולים לבחירה
- Top Gainers / Top Losers

## הרצה מקומית

```bash
python3 -m http.server 4173
```

ואז לפתוח: http://localhost:4173

> מקור הנתונים: Financial Modeling Prep עם מפתח `demo`.
> אם הקריאה נכשלת, הממשק עובר אוטומטית לנתוני דוגמה.
